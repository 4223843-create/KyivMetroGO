### THE LOGICAL ARCHITECTURE WE MUST PRESERVE
We must strictly adhere to the original two business rules of the app without relying on fragile array indices:
- Rule 1 (One-to-one): Every real passenger direction has exactly one real exit. Tapping any pin must check in all pins from all real passenger directions (e.g., Vokzalna).
- Rule 2 (By label): If at least one real passenger direction has more than one exit, only sync exits whose `exit.label` matches the label of the clicked exit (case-insensitive, whitespace-normalized). If the clicked exit has no label, do not sync (save the clicked pin only).

### THE TWO GENUINE BUGS TO FIX
1. The `allHaveOneExit` bug: The original code evaluated `station.directions.every(...)` blindly, which included service directions (like `__long_transfer__` or empty technical tracks). Because service tracks don't have exactly 1 exit, `allHaveOneExit` incorrectly evaluated to `false`, silently breaking Rule 1 for many stations. We must isolate "Real Directions" first. A "Real Direction" is a non-service track containing at least one exit with at least one active, non-closed position.
2. The empty `dir` bug on terminal stations ("Heroiv Dnipra"): Due to a split-block DOM rendering layout on terminal tracks, the UI layer extracts an empty string (`dir = ""`) when clicking a wagon pill.
